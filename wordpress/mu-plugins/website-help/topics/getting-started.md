# Where website content is managed

Studio Zanetti uses WordPress as the content editor and a separate React frontend as the public website. A visual element on the public site may therefore be controlled by a page, a reusable gallery, a menu, a blog post, media details, or shared Site Settings. Start by identifying the kind of change before editing anything.

## Choose the right place

- **Page wording, sections, buttons, page images, pricing, FAQs, or an enquiry form:** open **Pages**, then edit its **Page Blocks**.
- **A collection of photographs reused on one or more pages:** open **Gallery Library**. The page chooses that collection through a **Gallery Reference** block.
- **Which links visitors see in a header or dropdown:** open **Appearance > Menus**.
- **Which header menu a page uses:** open the page's **Page Settings**, or use the **Site Menus** view. This is separate from adding a visible navigation link.
- **An article:** open **Posts**. Article grouping is under **Posts > Categories**.
- **An uploaded image's alternative text, caption, or editor folder:** open **Media > Library**.
- **Footer details, social links, public business facts, photographer details, or the Service Catalog:** open **Site Settings**. These values can affect many pages.
- **Search titles, descriptions, social previews, or audit findings:** open **SEO, AI & Social**.

## Before changing something

1. Confirm whether the change should affect one page, every use of a reusable item, or the whole website.
2. Open the existing item rather than creating a near-duplicate.
3. For a large change, duplicate the page or note its current state first.
4. Save as a draft and preview before publishing when the item is new.
5. Check desktop and mobile views and follow the pre-publish checklist.

## Useful follow-up questions

Website Help can explain which screen controls an element, whether a value is local or shared, how to preview safely, what to check before publishing, and what information to include in a webmaster request. If the element cannot be identified from the question, provide the public page name, the visible text near it, and whether it appears on one page or many pages. Do not include passwords, customer enquiries, or private recipient details.
