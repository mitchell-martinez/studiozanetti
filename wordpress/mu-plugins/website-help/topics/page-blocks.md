# Page block reference

Open a page and choose **Add Row** in **Page Blocks**. Choose a block by the job it needs to do, not just by how it looks on another page. Existing blocks may expose shared section theme and top/bottom spacing controls; use those for page rhythm instead of adding empty blocks.

## Choosing a layout

1. **Hero:** the opening image or slideshow, main page title, supporting copy, and primary calls to action. Normally owns the page's single H1. Check text readability on every image and mobile crop.
2. **Text Block:** headings and longer rich text. Use a logical heading level, short paragraphs, lists where useful, and descriptive link text.
3. **Image + Text:** one image paired with explanatory copy. Controls can include desktop/mobile images, position, crop ratio and alignment, caption, text alignment, size limits, and an optional whole-block link. A whole-block link should have one unambiguous destination.
4. **Services Grid:** repeated service cards. Link a card to a **Global Service** only when it represents that authoritative Site Settings service; leave it blank for page-specific offerings.
5. **Pillar Grid:** concise principles, benefits, or process points of roughly comparable importance. It is not ideal for long prose.
6. **FAQ Accordion:** visible questions with complete answers. Write questions in visitor language. Do not use FAQ content solely to target search terms, and do not assume it will receive a Google rich result.
7. **Form:** an enquiry form with approved field types and delivery modes. Keep its stable Form ID, required Name field, and delivery configuration intact; use the Forms guidance before changing it.
8. **Pricing Packages:** comparable package names, price labels, benefit-led summaries, pricing detail, inclusions, and calls to action. Use a qualifier such as “From” when a figure is not a fixed total. Feature only the package that should receive visual emphasis.
9. **Gallery Categories:** image-led links to gallery destinations. Each item needs an accurate title, representative image, and valid destination; this is navigation, not the photo gallery itself.
10. **Gallery Reference:** displays one reusable **Gallery Library** entry. The optional block heading is page-specific; leaving it blank hides the heading rather than copying the gallery's internal title. Desktop columns allow 2–4 and mobile columns allow 1–3.
11. **Image Block:** a full-width image treatment with height, overlay, title/subtitle, alignment, motion, and accessibility options. Add enough overlay for readable text. A zero heading opacity makes heading text invisible and should not be used to hide meaningful content.
12. **Button Group:** one or more clear calls to action. Use short labels that describe the result, check every destination, and avoid several competing primary actions.
13. **Text Grid:** repeated compact text items for scannable information. Use a Text Block instead when each item needs substantial explanation.
14. **Instagram Feed:** a manually curated group of images and links styled like an Instagram feed. It does not connect to Instagram or import new posts automatically.
15. **Blog Posts:** a configurable list of published articles. Creating the block does not create posts; manage articles and categories under **Posts**.

## Shared quality checks

- Required repeaters need complete rows; remove abandoned empty rows.
- Select existing Media Library images and maintain meaningful alternative text there.
- Keep heading order logical even when visual styles look identical.
- Preview at desktop, tablet, and mobile widths after changing layout, columns, image crops, or overlay text.
- Test buttons and linked cards. Do not use a placeholder destination on a published page.
- If a block's visible controls cannot express the required behavior, it is a development request rather than an editor setting.

Website Help can compare suitable existing blocks, explain visible controls, inspect a narrow block scope with permission, and prepare a webmaster request. It cannot add a new layout, invent a hidden option, or modify the page.
