# SEO, social previews, and searchability audit

Open **SEO, AI & Social** for two different jobs: editing search/social previews and reviewing deterministic content-quality findings. These tools improve the information the site provides; they cannot guarantee ranking, traffic, rich results, or inclusion in AI-generated answers.

## Search and social previews

1. Find the correct saved page in **Search & Social Previews**.
2. Write a canonical title that identifies the page accurately. Avoid repeating the same generic title across pages.
3. Write a concise description that matches visible content and gives a useful reason to visit. Do not promise services, locations, or prices absent from the page.
4. Choose a representative featured image whose crop remains understandable in a preview card.
5. Wait for the screen's save status to confirm the change, then inspect the page and preview again.

Search engines and social platforms may cache old previews. A correct saved change may not appear immediately when a link is shared again. Website Help cannot clear third-party caches.

## AI Searchability Audit

The audit reads saved page content, metadata, images, and public entity inputs. It does not call an AI provider and is not a score of whether an AI system will cite the site.

1. Search or filter by page, status, or finding category.
2. Expand one page and read each finding's evidence and suggested action.
3. Use its remediation link to edit the responsible page, Media item, or Site Settings value.
4. Save that source, return to the audit, and choose **Refresh Audit** for the page.

Most findings are advice. Exactly one visible H1 is the enforced publishing rule: zero or multiple H1 headings block page publishing. A Hero title normally supplies the H1; later sections normally use H2/H3 levels. Container-only pages are outside audit scope.

## Interpret findings carefully

- Fix factual inconsistency before adding more keywords.
- Keep page titles, descriptions, headings, visible copy, services, venues, and business details consistent.
- Use public, verifiable structured-data facts and leave optional fields blank rather than guessing.
- Do not create repetitive FAQ, location, service, or award text solely to satisfy a check.
- Review image alternative text and rights metadata in the Media Library, where shared attachment values are maintained.

Website Help cannot promise performance, submit indexing requests, access Search Console, clear social caches, or edit metadata. Contact the webmaster for persistent indexing failures, structured-data validation errors, canonical/redirect changes, or frontend output that differs from saved metadata.
