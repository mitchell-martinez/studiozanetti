# Safe editing, revisions, trash, and recovery

Use a reversible workflow when a change is substantial, unfamiliar, or affects shared content.

## Safest workflow

1. Confirm that you opened the correct page, post, gallery, menu, or shared setting.
2. For a major page or post redesign, use **Duplicate** from the list screen and work on the draft copy. A duplicate must receive its own title and slug before publication.
3. Make one logical group of changes at a time.
4. Use **Save Draft** for unfinished new content or **Update** for an existing item only when you intend to change its saved version.
5. Refresh the Live Front-End Preview and check desktop, tablet, and mobile widths.
6. Keep the old browser tab open until the save succeeds.

WordPress autosave can reduce loss, but it is not a substitute for an intentional save. Preview may include the latest autosave or revision, while the public page continues to show the last published version.

## If something went wrong

- **The editor still contains the correct unsaved text:** copy important text somewhere safe before refreshing. Read the notice and try saving once.
- **A page or post was saved incorrectly:** look for the **Revisions** panel on its editor. Compare timestamps and authors carefully before restoring. Restoring a revision replaces the current saved content, so preview it afterward.
- **An item was moved to Trash:** open that content type's list, choose **Trash**, then restore it if it is present. Do not recreate it first, because that can produce duplicate slugs or menu items.
- **A reusable gallery was changed accidentally:** stop before editing pages that reference it. Restoring the gallery changes every page that uses that same gallery.
- **A menu or Site Settings value was changed:** these are shared and may affect many pages. Record what changed and contact the webmaster if the previous value is uncertain.
- **Content is absent from both Revisions and Trash:** Website Help cannot recover deleted database records, files, or server backups. Contact the webmaster promptly with the item title, approximate time, and last known correct state.

## Avoid making recovery harder

Do not repeatedly save, refresh, empty Trash, upload replacement copies, or create similarly named pages while investigating. Do not share private preview links. Website Help can explain recovery controls but cannot restore or delete content itself.
