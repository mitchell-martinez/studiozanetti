# Media Library, folders, and image details

The Media Library stores reusable files; page and gallery fields select those files. Editing one attachment's details can affect every place that reuses it, while changing a block's crop or display settings usually affects only that block.

## Add and prepare an image

1. Search the library before uploading. Reuse the existing attachment when it is the same photograph.
2. Upload a web-ready image once. Extremely large source files slow uploads and processing; ask the webmaster when you are unsure about preparation.
3. Open **Attachment details** and write concise alternative text for meaningful images. Describe the useful visible subject in context rather than writing “image of,” stuffing keywords, or copying a filename.
4. Add a caption only when visitors should see additional context, attribution, or explanation beneath the image.
5. Assign an editor folder if useful, then save the attachment details.

Alternative text belongs to the attachment and can be reused across the site. If the same image has a different purpose in one unusual context, check whether that block provides its own accessible label rather than changing a globally suitable description.

## Folders and file identity

Use **Media > Folders** and the list-view folder filter to organize assets. Folders are editor-only labels: moving or renaming a folder does not move the physical file, change its public URL, or alter pages using it. Renaming an attachment title also does not rename the uploaded file.

Do not delete an attachment merely because it is absent from the current page. It may be used by another page, post, gallery, social preview, or structured-data field. Uploading a second copy does not replace the first and can make future selection confusing.

## Public image metadata

Selected attachments expose image-search fields for factual caption, creator, credit, copyright notice, licence, acquisition page, and location information. Complete only facts that are true, public, and supported by the rights held for that image. Leave optional fields blank rather than guessing. Do not add private client information solely for search visibility.

## Check after selection

Preview the image at desktop, tablet, and mobile widths. Confirm the focal subject survives any crop, overlaid text remains readable, the file is not visibly soft or pixelated, and captions/credits appear only where expected.

Website Help cannot upload, crop, replace, delete, or reorganize files. Contact the webmaster for bulk cleanup, suspected duplicate files, broken thumbnails, upload/processing errors, or safe replacement of an image while preserving existing uses.
