# Previewing, publishing, and duplicating

The editor, preview, and public website represent different states. The editor can contain unsaved changes; preview can use the latest autosave or revision; the public URL shows the last published version.

## Preview safely

1. Save a new page as a draft once so it has an ID and preview can load.
2. In **Live Front-End Preview**, choose **Refresh Preview** after edits. It does not refresh continuously. `Ctrl+Shift+P` also refreshes it.
3. Use the Desktop, Tablet, and Mobile controls. Full Screen provides more room but does not change the content.
4. Clicking a supported section inside the preview can jump to and highlight its Page Block fields.
5. Check the exact content, image crop, heading order, spacing, links, and form layout before saving or publishing.

If preview looks older than the editor, confirm autosave has finished and refresh the preview once. If it still differs, save deliberately, reload once, and compare again. Do not repeatedly publish different guesses.

Preview URLs use private server configuration to show unpublished work. Do not share them as public links.

## Understand the save actions

- **Save Draft:** stores unfinished content without making a new page public.
- **Publish:** makes a new page or post public.
- **Update:** replaces the saved version of an already published item.
- **Move to Trash:** removes the item from normal use but is not the same as immediately deleting it permanently.

Publishing does not add a page to navigation. Removing a menu link does not unpublish its page. Changing a slug or parent can change the public URL, so review incoming links and navigation before making that structural change.

## Duplicate without creating confusion

From the Pages or Posts list, use **Duplicate** when an existing structure is a useful starting point. The copy is created as a draft. Immediately review its title, slug, body or Page Blocks, featured image, Page Settings, categories, SEO description, reusable references, and menu placement. Do not publish a copy that still resembles the source page in title, URL, or metadata.

For mistakes, use the safe editing and recovery guidance. Website Help cannot save, preview, duplicate, publish, unpublish, trash, or restore content. Contact the webmaster when preview remains unavailable after the first draft save or the public result remains stale after one normal refresh.
