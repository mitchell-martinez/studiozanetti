# Pre-publish website quality checklist

Use this checklist before publishing a new page or post and after a significant update. A preview is the evidence; the editor fields alone are not enough.

## Content and structure

- The title, spelling, dates, prices, names, and contact details are correct.
- The page has one clear visible H1. A Hero title is normally the H1; later section headings normally begin at H2.
- Buttons describe their destination or action and lead to the intended page.
- No placeholder copy, empty repeated item, duplicate section, or accidental draft text remains.
- Shared facts such as services, business details, and venues agree with Site Settings and authoritative sources.

## Images and accessibility

- Each meaningful image has concise alternative text describing the useful visible content.
- Decorative images do not repeat nearby text unnecessarily.
- Captions are used only when visitors need to see extra context or attribution.
- Important subjects remain visible in desktop, tablet, and mobile preview crops.
- Text over images remains readable and controls can be understood without relying only on colour.

## Navigation and discovery

- The slug is short, accurate, and final before sharing the page.
- Publishing a page does not add it to navigation automatically; add or remove the menu item separately.
- The page has the correct Menu Override, parent, category, and Primary Service where applicable.
- Search title, description, featured image, and visible page content agree.
- Relevant AI Searchability Audit findings have been reviewed. Passing the audit does not guarantee ranking or traffic.

## Functional checks

- Preview the desktop, tablet, and mobile layouts.
- Test each important button and link.
- For a form, submit a non-sensitive test enquiry and confirm the expected delivery path.
- For a gallery, inspect ordering, captions, empty spaces, and image crops.
- For shared Site Settings or reusable galleries, inspect more than one affected page.

## Publish deliberately

Use **Save Draft** when review is incomplete. Use **Publish** for a new item or **Update** for an existing one only after the checks above. Then open the public URL in a fresh tab and confirm the change. If the public result differs from preview after a normal refresh, stop repeated edits and use the troubleshooting guidance.
