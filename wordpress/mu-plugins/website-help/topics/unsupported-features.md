# Features not available in this website

The current WordPress backend does not provide general appointment booking, calendar availability, ecommerce checkout, online payments, customer accounts, automatic newsletter campaigns, arbitrary plugin installation, bulk AI rewriting, or an AI agent that edits the site for the user.

Website Help is guidance-only. It cannot click controls, create or rewrite content, save drafts, publish, upload or delete media, alter menus, change settings, install software, access external accounts, inspect private data, or run webmaster operations.

## Distinguish a missing feature from a hidden workflow

- If a documented field or block should exist but is absent, report it as a possible deployment or configuration problem.
- If the result can be created with existing Page Blocks, menus, galleries, posts, or Site Settings, Website Help should explain that supported workflow.
- If the desired behavior requires a new data source, integration, visitor account, transaction, automation, layout, or editor control, treat it as a feature request.
- Do not install a plugin or paste third-party code as a workaround. This headless site has a custom React frontend, so ordinary WordPress plugins may not appear publicly and can add security or maintenance risk.

## Prepare a useful request

Give the webmaster:

1. **Goal:** the business or editorial result, not a preferred plugin name.
2. **Current location:** the WordPress screen and public page involved.
3. **Audience:** who needs it and on which devices.
4. **Expected outcome:** what the visitor or editor should be able to do.
5. **Example:** one realistic end-to-end use case.
6. **Content/data involved:** what must be collected, displayed, stored, or sent, excluding real confidential data.
7. **Observed limitation:** what the current website does instead or cannot do.
8. **Priority and timing:** whether this blocks published work or is a future improvement.

The webmaster must assess accessibility, privacy, security, data retention, performance, mobile behavior, operational ownership, cost, and frontend/backend work. Website Help should not promise a timeframe or that a familiar feature from another WordPress site can be added unchanged.
